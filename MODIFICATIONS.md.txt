## 🚀 Déploiement

### Option 1 : Déploiement sur **Netlify** (recommandé)

1. **Créez un compte** sur [Netlify](https://www.netlify.com/) (gratuit).
2. **Glissez-déposez** le dossier `baracca-website` dans l'interface Netlify.
3. **Attendez** quelques secondes : votre site sera en ligne !
4. **Personnalisez** le nom de domaine (ex: `baracca.netlify.app`).

> ✅ **Avantages** : Déploiement en 1 clic, SSL automatique, formulaires gérés (Netlify Forms).

---

### Option 2 : Déploiement sur **GitHub Pages**

1. **Créez un dépôt GitHub** (ex: `baracca-website`).
2. **Poussez** le code dans le dépôt.
3. **Activez GitHub Pages** :
   - Allez dans **Settings > Pages**.
   - Sélectionnez la branche `main` et le dossier `/ (root)`.
   - Cliquez sur **Save**.
4. **Votre site sera disponible** à l'URL : `https://votre-utilisateur.github.io/baracca-website/`

> ⚠️ **Note** : Les formulaires ne fonctionneront pas avec GitHub Pages (utilisez Netlify).

## ⚙️ Personnalisation

### 1. Modifier le contenu
- **Textes** : Éditez directement les fichiers `.html` avec un éditeur de code (VS Code, Sublime Text, etc.).
- **Images** : Remplacez les images dans `assets/images/` par vos propres visuels.
- **Couleurs** : Modifiez les variables CSS dans `assets/css/style.css` (ex: `--primary: #4A9B8E;`).

### 2. Mettre à jour le compteur de levée de fonds
Dans le fichier `investir.html` et `investisseurs.html`, modifiez la valeur :
```javascript
const amountRaised = 250000; // Remplacez par le montant actuel

Actualités de l'espace investisseurs alimentées par le blog

La section « Actualités » de `investisseurs.php` affiche désormais les
derniers articles publiés sur le blog (`blog.baracca.fr`), au lieu de
cartes écrites à la main.

Fonctionnement :
- Le blog expose un flux JSON public : `blog.baracca.fr/api-articles.php`
  (articles publiés uniquement : slug, titre, catégorie, date, extrait).
- `includes/blog.php` récupère ce flux (timeout 5 s) et construit les
  liens vers le blog : relatifs en local (`../blog.baracca.fr`), absolus
  en ligne (`https://blog.baracca.fr`).
- Si le blog est injoignable, la section affiche un message discret
  sans casser la page.
